# @mikhaylovabeauty_bot

Telegram-бот Валерии Михайловой — запись на услуги (разбор косметички, маникюр, педикюр, онлайн-сопровождение макияжа).

## Что внутри

- `bot.py` — основной скрипт
- `requirements.txt` — зависимости (pyTelegramBotAPI)
- `Procfile` — для Railway/Render (worker = python bot.py)
- `photo-*.jpg` — фото-превью по услугам

## Что умеет

- Главное меню с 4 услугами + кнопки «Обо мне» / «Связаться»
- Фото-превью для каждой услуги
- Подварианты (для маникюра/педикюра)
- Сценарий: услуга → имя → телефон → дата → подтверждение → заявка владельцу
- Заявки улетают:
  - владельцу (Валерии) в личку `OWNER_CHAT_ID`
  - в топик «Сайт» спру (Алефтине) для контроля

## Деплой на Railway — 5 минут

1. Зарегистрируйся на https://github.com (если ещё нет)
2. Создай новый репозиторий (кнопка «+» → «New repository»)
3. Залей туда все файлы из этой папки (можно через «Add file» → «Upload files»)
4. Зайди на https://railway.app → «Login» → «Login with GitHub»
5. Нажми «New Project» → «Deploy from GitHub repo» → выбери свой репозиторий
6. Railway увидит Procfile и задеплоит
7. В настройках сервиса → Variables → добавь:
   - `BOT_TOKEN` = токен бота (уже есть у тебя)
   - `OWNER_CHAT_ID` = `1194243262`
   - `ADMIN_CHAT_ID` = `358325979`
   - `ADMIN_TOPIC_ID` = `225548`
8. Нажми Deploy → открой бота @mikhaylovabeauty_bot в Telegram → /start
